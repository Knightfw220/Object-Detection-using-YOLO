# Object Detection using YOLO

YOLO is a real-time object detection algorithm that detects objects in images and videos by predicting bounding boxes and class probabilities in a single forward pass through a neural network.

## Theory Overview

### Object Detection
Object Detection is a computer vision technique used to identify and locate objects in an image or video.
It not only tells what objects are present, but also where they are by drawing bounding boxes around them.

---

### YOLO (You Only Look Once)
YOLO is a real-time object detection algorithm.
Unlike traditional methods that scan the image multiple times, YOLO looks at the image **only once** and predicts
all bounding boxes and class labels in a single pass.
This makes YOLO very fast and suitable for real-time applications.

Key advantages of YOLO:
- High speed
- Good accuracy
- Works well for real-time detection

---

### OpenCV
OpenCV (Open Source Computer Vision Library) is a popular library used for image and video processing.
It provides tools to:
- Read images and videos
- Draw bounding boxes and labels
- Perform image transformations
- Integrate deep learning models like YOLO

OpenCV acts as the bridge between the detection model and real-world image/video input.

---

### Why YOLO + OpenCV?
YOLO handles **object detection**, while OpenCV handles **image/video processing and visualization**.
Together, they allow building fast and practical object detection systems.
